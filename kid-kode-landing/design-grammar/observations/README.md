# Observation seeds (ground truth inputs)

Seeds written by the founder's interactive monitor session (full browser +
vision) and by this wave's Playwright motion-protocol runs land here. They
are GROUND TRUTH for family distillation (founder addendum 2026-07-06).

- Format: free-form Markdown or the per-site analysis JSON from the analyst
  brief — the orchestrator normalizes either into `families/<family>.json`.
- Seeds must already be principle-distilled, own-words descriptions (legal
  doctrine). Screenshots NEVER land here — they stay in `/tmp/wdg1-scratch/`
  and are deleted at wave end.
- Once a seed is fully distilled into family docs, the distillation is
  recorded in the family's `sources[].observationRef`.
