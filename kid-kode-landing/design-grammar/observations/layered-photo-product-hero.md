# OBSERVATION SEED 01 — FAMILY: layered-photo product hero
# Source: interactive analysis (scroll sequence, 4 states) of the Zero Point
# template, 2026-07-06, by founder monitor session. This file contains ONLY
# original technique analysis. No source assets, code, or copy are stored.

## STRUCTURE (z-order, back to front)
1. Full-bleed backdrop plate (moody, low-detail, strong color cast).
2. Oversized display typography — INTERLEAVED with the product layer so the
   headline passes BEHIND the hero object (cheap, powerful depth illusion).
3. Product hero: photographic/pre-rendered CUTOUT, not realtime geometry.
4. SEPARATE shadow plate under the product (soft, detached — sells weight).
5. 8-12 floating garnish cutouts (fruit/ingredients) at varied scales/blur.
6. Foreground glow, particles, subtle lens bloom.

## MOTION CHARACTER
- Differentiated parallax: each layer scrolls/drifts at its own rate.
- Garnish elements float on slow independent loops (position + slight
  rotation); product has a subtle idle bob. Nothing is static; nothing is
  fast. "Alive, not busy."
- Slide/theme transitions: palette hue + garnish set + backdrop swap with
  snappy eased motion; type re-animates per state.
- Scroll drives section state changes.

## PALETTE LOGIC
One saturated brand hue per state on deep near-black; neon rim glow keys the
product to the hue; garnish colors match the flavor/theme hue. High contrast,
single-hue discipline per state.

## WHY IT READS AS REAL
Photographic asset quality + detached soft shadow + bloom. The realism is in
the SOURCE IMAGERY and shadow/glow compositing, not geometry or materials.

## PRISM MAPPING (route R2/R3 composite)
FLUX 2 Pro photoreal product render -> background removal -> cutout layer;
synthesized soft shadow plate; garnish set generated per theme; palette
tokens drive per-state theming; z-interleaved display type via text-3d
primitives; parallax + idle-loop + transition via animatable primitives;
bloom/grain/grade via post stack (W-PHOTO). GAP CHECK for report: confirm
background-removal + shadow-plate synthesis exist in media-gen adapters.

## WHEN TO USE / NOT
Use: product showcases, flavor/variant storytelling, bold single-product
brands. Avoid: dense content hubs, multi-product grids (garnish noise
competes), conservative/professional briefs.
