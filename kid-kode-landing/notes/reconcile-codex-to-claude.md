## `verify-prism.mjs` reconciliation

Two-version starting point:

- **prism-main** (209 lines): 5 static-source `forbidden:*` checks (walks `src/`) + 10 strict
  `.prism` artifact checks. Designed for the pre-migration PixiJS-era artifact pipeline
  (`mock-app-source/build-prism.mjs` against the 40-node `hubs/home-hub.json`).
- **codex** (109 lines): artifact-only, with a renderer-era node-fields check and an
  artifact-text Pixi scan. Designed for the post-migration pipeline
  (`scripts/build-live-prism.mjs` against `public/prism-mock/home/live-graph.json`).

The kept runtime work includes the new build pipeline, which produces a renderer-era
artifact with different node shape and a smaller starting graph (currently 6 nodes,
`hubId='home'`, empty `codeRef`, no legacy `animationSpec.method` / `regionKeys`). Several
prism-main strict checks therefore no longer apply.

Final reconciled inventory (14 checks, all PASS — see Verification below):

**KEPT (5) — static-source `forbidden:*`** (applies pre- and post-migration):
`forbidden:PIXI.Text`, `forbidden:PIXI.Text.ref`, `forbidden:PIXI.Graphics`,
`forbidden:html-to-image`, `forbidden:innerHTML+fillText`.

**KEPT (5) — artifact checks that still apply** (no change vs prism-main):
`prism:manifest`, `prism:artifactHash`, `prism:asset.sha256`, `prism:backends.loadable`,
`prism:text.methods`.

**RELAXED (1):** `prism:entryHub` — was strict `=='home-hub'`, now flexible
`manifest.entryHub === graph.hubs[0].hubId`. The new `build-live-prism.mjs` uses
`hubId='home'`; the real invariant is "entryHub identifies a real hub in graph.hubs[]".

**ADDED (3) — from Codex's renderer-era version, strengthened where useful:**

- `prism:renderer-graph` — every `graph.nodes[]` has `renderMode` (one of the 4 valid
  modes per spec §8), `scenePosition`, and a `cinematicPrimitives` array (spec §7). This is
  the structural replacement for the dropped legacy checks.
- `prism:nodeCount.consistency` — `manifest.nodeCount === graph.nodes.length`. Catches
  manifest/graph drift without imposing a size minimum.
- `prism:no-pixi.artifact` — scans every text entry inside the built `.prism` for Pixi
  references. Complementary to the static-source `forbidden:PIXI.*` checks: catches Pixi
  sneaking in via a build path that bypasses `src/`.

**DROPPED (4) — prism-main checks encoding pre-migration invariants:**

- `prism:nodeCount` (≥30 realism). Stale: was a hard floor tied to the 40-node home-hub
  artifact. The new live-graph.json artifact starts smaller and grows as the editor adds
  nodes. Replaced by `prism:nodeCount.consistency`.
- `prism:node.module.presence` (every node has a `nodes/<codeRef>.js` module). Stale:
  renderer-era nodes render via `renderMode` + `cinematicPrimitives` instead of per-node
  JS modules, and `codeRef` is intentionally empty. Replaced by `prism:renderer-graph`.
- `prism:three.methods` (animation methods 1, 2, 3 all present). Stale: PixiJS-era
  `animationSpec.method` codes superseded by spec §7 `cinematicPrimitives`. Replaced by
  `prism:renderer-graph` (which asserts `cinematicPrimitives` is an array per spec).
- `prism:layer.swap` (at least one node uses `regionKeys`). Stale: PixiJS-era
  regionKeys/regions mechanism superseded by spec §8 `renderMode` + `depthMapUrl` +
  cinematic primitives. Structurally validated by `prism:renderer-graph`.

The inline header of `kid-kode-landing/scripts/verify-prism.mjs` mirrors this table.

**DROPPED from Codex** (subsumed by kept prism-main equivalents):
- Codex's `prism:assets` — duplicate of `prism:asset.sha256`.
