## Architecture facts established (Phase 0 orientation)
- three@0.184, `@react-three/fiber@9`, allowlisted deps: `simplex-noise@4`, `d3-force-3d`, `gsap@3.13`. **No rigid-body engine, no fluid lib in the allowlist** — adding one needs the dep guard (`.claude/hooks/dependency-allowlist-check.py`) edited + rationale in `notes/mockup-pipeline.md §10`.
- Gold-standard sim pattern: `collision-balls.ts` — deterministic fixed-dt CPU integrator, reset-on-backward-seek, fixed MAX allocation, `duration()=Infinity`. No `Math.random` (uses `sin`-hash seeding).
- **Key insight:** the reset-replay integrator makes the frame at `t` a pure function of `(params, t)`, so EVERY control is automatically frozen-frame-visible to the advocate harness (which sweeps controls at a pinned `t` via `__catalogRig.seek`). This neutralizes the "dead control at engaged pose" failure mode that cost prior waves 2-3 fix-rounds each.
- Tile rig (`shared-tile-renderer.ts`): one WebGPU canvas, scissored per-tile. Subjects via `buildSubject(def.subject)`. Pointer stimulus `userData.pointer` (normalized 0..1, center 0.5,0.5); scroll stimulus `userData.scroll` (0..1). Camera z≈3.2, FOV40, subject fills ~±1.4.
- Categories FROZEN (15): no `physics`/`fluid` category. Sim primitives map onto existing categories (particles / transform / pointer / displacement / wave / caustics / glass / smoke).
- Harness `verify-catalog-parallel.mjs`: real Metal-GPU (webgpu) tier for `glass`+`caustics`+`GLASS_EXTRA` names; std tier (SwiftShader) for the rest. Fluids → route to real-GPU via `GLASS_EXTRA` additions.
- Barrel `primitives/index.ts` is AUTO-GENERATED by `notes/catalog-wire-barrel.mjs` — re-run the wirer, never hand-edit.
